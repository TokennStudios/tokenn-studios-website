# Tokenn Studios

Official website for Tokenn Studios, an independent game development and digital asset studio.

## Brand direction

- **Primary look:** monochrome, cinematic, minimal
- **Colors:** Obsidian `#090A0C`, white `#F2F2F0`, steel gray `#A7A9AC`, antique gold `#C8913A`
- **Display type:** Cinzel
- **Body type:** Montserrat

## Website sections

- Studio introduction
- Gauntlet Modern project showcase
- Upcoming asset collections
- Studio contact information

## Run locally

This is a static HTML, CSS, and JavaScript site. Open `index.html` in a browser, or use a local development server.

## Publish with GitHub Pages

1. Open the repository's **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`.
5. Save and wait for the deployment workflow to finish.

The published address will be `https://tokennstudios.github.io/tokenn-studios-website/`.
